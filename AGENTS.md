# Инструкции для работы в репозитории

- Общаться по-русски, кратко. Не выдавать планы и предположения за выполненную работу.
- Разработка сайта, TraceShelf, QuietSlot и RePair Atlas разрешена. Личные данные, фото и контакты публикуются по предоставленной пользователем информации; не дополнять их выдуманными фактами. Все три проекта — рабочие локальные MVP.
- Фронтенд: React + TypeScript. Для SPA — Vite + React Router; Next.js — когда нужны SSR/серверные функции, вместо Vite.
- Серверное состояние — TanStack React Query; клиентское — Zustand. Не дублировать кеш запросов в Zustand.
- Оформление по умолчанию — Tailwind CSS. Astryx — допустимая альтернатива пользователя; точный пакет и совместимость сначала уточнить и проверить, не устанавливать по догадке.
- Формы — React Hook Form; проверка данных — Zod. Использовать по потребности.
- Эти правила действуют для apps/ и projects/. Смена стека требует согласования.
- GitHub Pages обслуживает статические файлы. Секреты и серверные API не помещать во фронтенд. Для SPA на Pages использовать hash-маршрутизацию, если не согласован другой способ.
- Перед завершением запускать npm run check. Когда появится интерфейс — добавить поведенческие тесты Vitest/Testing Library и E2E Playwright для ключевых сценариев, включая клавиатуру и мобильный экран.
- Не придумывать метрики, отзывы, клиентов или результаты для кейсов. Демоданные явно помечать.
- Не публиковать сайт и не создавать удалённый репозиторий без соответствующего запроса.

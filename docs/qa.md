# Проверка портфолио

## Матрица сценариев

| Требование / контроль   | Проверка                                                                                            |
| ----------------------- | --------------------------------------------------------------------------------------------------- |
| Адаптивная главная      | Скриншоты desktop/mobile, ширины 320 / 390 / 768 / 1024 / 1440, отсутствие горизонтального скролла  |
| Личные данные и проекты | Личные данные и два концепта — заглушки; TraceShelf имеет реальный скриншот и рабочую ссылку на MVP |
| Фильтры проектов        | Три карточки → приложения (2) → эксперименты (1) → все (3); aria-pressed и статус для скринридера   |
| Страница проекта        | Переход с карточки, обновление адреса, возврат к списку                                             |
| Тема                    | Переключение светлая/тёмная, сохранение после обновления, визуальная проверка обоих вариантов       |
| Навигация               | Секции, мобильное меню, закрытие по Escape, возврат фокуса, skip-link                               |
| Ошибка данных           | Неверная схема JSON → ошибка → повторный запрос                                                     |
| Неизвестный маршрут     | Страница 404 с переходом на главную                                                                 |
| Ограничение анимации    | prefers-reduced-motion отключает плавную прокрутку и переходы                                       |

Автоматизация: `npm run test` и `npm run test:e2e`. Внешних API и формы отправки нет. Проверки в эмуляции Chromium не заменяют проверку на физических устройствах и других движках.

# Инструменты

## Установлено локально

- npm workspaces, React/TypeScript/Vite и согласованные фронтенд-библиотеки.
- ESLint с правилами React Hooks, Prettier, строгий TypeScript.
- Навыки Codex из openai/skills: playwright, playwright-interactive, screenshot, gh-fix-ci, gh-address-comments, security-best-practices.

Плагины GitHub и Figma уже установлены: статус проверен через каталог плагинов. Это не подтверждает доступ к конкретному репозиторию или дизайн-файлу; он проверяется при обращении. Навыки Figma уже доступны через установленный плагин.

Установлены Vitest, Testing Library, jsdom, Playwright Test и локальный Chromium. Компонентные тесты проверяют фильтрацию, маршруты, ошибку загрузки, тему и меню. E2E проверяют интерфейс в desktop и мобильной эмуляции. В CI Chromium устанавливается перед браузерными тестами.

Дата проверки: 2026-10-28. Дополнительные сервисы деплоя не нужны для подготовки под GitHub Pages.

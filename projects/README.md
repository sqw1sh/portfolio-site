# Проекты на показ

Все три проекта — авторские предложения для разработки, не готовые продукты. Глобальная уникальность идей не проверена и не заявляется.

| Проект                                 | Основная задача                                                            | Что показать работодателю                                    |
| -------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------ |
| [TraceShelf](traceshelf/README.md)     | Проверять, на каких источниках держится решение команды                    | Граф зависимостей, типизированные данные, актуальность кеша  |
| [QuietSlot](quietslot/README.md)       | Находить время встречи с минимальным неудобством для разных часовых поясов | Алгоритмы, объяснимый рейтинг, работа с датами и доступность |
| [RePair Atlas](repair-atlas/README.md) | Планировать ремонт техники через зависимости и совместимость деталей       | Сложные формы, граф шагов, сравнение сценариев               |

В каждом каталоге: README со спецификацией, app/ для будущего приложения, design/ для макетов, assets/ для материалов, docs/ для решений и QA.

Не реализовывать проекты до отдельного запроса. Для кейса фиксировать проблему, решения, ограничения, скриншоты и только реально измеренные результаты.

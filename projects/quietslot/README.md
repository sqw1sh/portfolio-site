# QuietSlot — справедливое время встречи

## Идея

Планировщик встреч для распределённых команд: показывает, кому неудобен каждый вариант, и учитывает, кто уже уступал в прошлых встречах.

## MVP

- Ввод участников, IANA-часовых поясов, рабочих окон и ограничений.
- Подбор вариантов по пересечению доступности и прозрачной функции штрафа.
- Тепловая карта и доступная таблица; объяснение оценки каждого слота.
- История распределения неудобных слотов и сравнение «разовая встреча / серия».
- Экспорт выбранной встречи в ICS без подключения к личным календарям.

## Архитектура

React + TS + Vite + React Router, Tailwind, React Hook Form + Zod. Zustand — редактор сценария; React Query — загрузка демосценариев через адаптер. Подходящую библиотеку работы с часовыми поясами выбрать и проверить перед реализацией. Время хранить как момент UTC с отдельным IANA-поясом.

## Критерии готовности

Тестировать переходы летнего времени, разные календарные даты у участников, окна через полночь и отсутствие пересечения. Оценка воспроизводима и объясняется пользователю. ICS открывается в совместимом календаре. E2E: создать команду → сравнить варианты → экспортировать.

## Кейс

Показать функцию ранжирования, пограничные случаи дат, клавиатурное управление и замеры скорости перебора на зафиксированном сценарии. Оптимальность не заявлять без доказательства.

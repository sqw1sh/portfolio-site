# RePair Atlas — конструктор маршрута ремонта

Рабочий локальный MVP на React + TypeScript + Vite, React Router, React Query, Zustand, Tailwind, React Hook Form и Zod.

## Запуск

Из корня: `npm ci`, затем `npm run dev:repair-atlas` (порт 4200). `npm run build` собирает портфолио и все три проекта; `npm run preview` обслуживает RePair Atlas по `/repair-atlas/`.

## Возможности

- Каталог двух вымышленных устройств, девяти деталей и трёх инструментов с явной пометкой демо.
- План из 1–30 шагов с длительностью, заметками, зависимостями и инструментами. Циклы, самоссылки и отсутствующие зависимости не сохраняются.
- Проверка формата устройства, ревизии контроллера и протокола модуля клавиш. Матрица объясняет конкретные конфликты.
- Сравнение текущего плана, сохранения штатных деталей и покупки новых. Сценарии используют одинаковые шаги, ставку и инструменты.
- Пошаговое прохождение: шаг доступен после завершения зависимостей и устранения конфликтов. Отмена шага снимает все зависимые отметки.
- Локальное сохранение, импорт и экспорт JSON. Импорт проверяет версию, каталог, граф и целостность прогресса; перед заменой требуется подтверждение.

## Модель и расчёты

Каталог загружается адаптером React Query и не копируется в Zustand. Zustand хранит только черновик. Zod проверяет структуру, DFS — отсутствие циклов, топологическая сортировка задаёт порядок. Каталог дополнительно проверяется при чтении черновика и импорте. Изменение маршрута или деталей сбрасывает прохождение; изменение ставки и наличия инструментов его сохраняет.

Детали «уже есть» стоят в смете 0 ₽. Нужные инструменты учитываются один раз по уникальному идентификатору, за исключением уже имеющихся. Работа = сумма минут × ставка / 60. Все слагаемые считаются в копейках, труд округляется до копейки. Нет расчёта доставки, налогов, параллельной работы или вероятности успешного ремонта.

Фиксированный пример Mica: 35 минут, контроллер 1 800 ₽, недостающие инструменты 1 010 ₽, работа по ставке 900 ₽/ч — 525 ₽, итог 3 335 ₽. Вариант всех новых модулей: 7 000 + 1 010 + 525 = 8 535 ₽. Это вымышленные цены, не рыночная оценка.

## Данные

Хранилище `repair-atlas.draft.v1` отделено от других приложений. При ошибке чтения исходная запись не заменяется автоматически. При ошибке записи остаётся предыдущий план; пользователь видит сообщение. Импорт ограничен 256 КБ, 30 шагами и каталогом v1. Некорректный импорт не меняет план. Потеря localStorage при очистке браузера возможна; JSON служит переносимой копией.

## Проверки

Из корня: `npm run check`, `npm run build`, `npm run test:e2e`. Подробная матрица — [QA](docs/qa.md). Модульные и компонентные тесты проверяют смету, совместимость, граф, прохождение, формы и отказоустойчивость хранилища. Playwright проверяет интерфейс через production-сборку в Chromium на desktop и мобильной эмуляции.

## Границы

Каталог, цены и этапы вымышлены. Приложение не является руководством по ремонту настоящей техники и не подтверждает её работоспособность. Нет аккаунтов, серверной синхронизации, фактического заказа деталей и внешних API. Экологический эффект, срок службы и успешность ремонта не измерялись.

# RePair Atlas — конструктор маршрута ремонта

## Идея

Интерактивная карта ремонта устройства: зависимости между шагами, совместимость деталей, нужные инструменты и сравнение стоимости вариантов.

## MVP

- Небольшой каталог вымышленных устройств и деталей с явной пометкой «демо».
- Редактор шагов ремонта с зависимостями и проверкой циклов.
- Матрица совместимости деталей и объяснение конфликтов.
- Сравнение сценариев: стоимость, длительность, повторно используемые детали; исходные допущения видимы.
- Сохранение плана локально, импорт/экспорт JSON, режим пошагового прохождения.

## Архитектура

React + TS + Vite + React Router, React Query для каталога, Zustand для черновика, Tailwind, React Hook Form + Zod. Для будущего общего каталога с авторизацией и серверной обработкой рассмотреть отдельное приложение Next.js; такой сервер не размещается на GitHub Pages.

## Критерии готовности

Нельзя начать шаг с незавершёнными зависимостями. Несовместимые детали дают конкретную причину. Расчёт стоимости проверяется на фиксированных примерах. Черновик восстанавливается после обновления страницы. E2E: выбрать устройство → собрать план → устранить конфликт → экспортировать.

## Кейс

Показать инварианты модели, сложную форму, восстановление состояния и сравнение вариантов. Не публиковать вымышленные инструкции как проверенные рекомендации по ремонту реальной техники.

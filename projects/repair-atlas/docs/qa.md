# QA RePair Atlas

## Матрица требований и интерфейса

| Возможность / контроль | Проверка                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| Устройства             | Mica → Orbit с подтверждением; отмена импорта и смена данных явно отделены                                     |
| Детали                 | Смена модуля, наличие детали, объяснение формата и протокола, блокировка прохождения при конфликте             |
| Матрица                | Все девять деталей, название, цена, тип, результат и причина                                                   |
| Редактор               | Пустое название, время, зависимости, инструменты; отклонение цикла без закрытия формы                          |
| Удаление               | Запрет удаления шага с входящими зависимостями, удаление конечного шага                                        |
| Смета                  | Фиксированные 3 335 / 8 535 ₽, уникальные инструменты, нулевая ставка, наличие деталей и инструментов          |
| Сравнение              | Три сценария, явные допущения, применение варианта с подтверждением                                            |
| Прохождение            | Недоступный следующий шаг, полный маршрут, перезагрузка, транзитивная отмена, отмена и подтверждение сброса    |
| JSON                   | Экспорт и чтение файла, подтверждение импорта, неверный JSON, нарушенный граф, неверный каталог, лимит размера |
| Хранилище              | Восстановление, повреждённая запись без автоперезаписи, нехватка места без потери предыдущего плана            |
| Навигация              | Переход из портфолио, прямые hash-маршруты, skip-link и клавиатура                                             |
| Адаптивность           | Маршрут, сравнение, матрица, прохождение; ширины 320 / 390 / 768 / 1024 / 1440                                 |
| Визуальная проверка    | Первый экран desktop/mobile, сравнение, конфликт, форма, матрица, прохождение и смета                          |

Тесты модели и компонентов: `projects/repair-atlas/app/src/*.test.*`. Браузерные: `tests/e2e/repair-atlas.spec.ts`. Команды запускаются из корня репозитория.

Проверки браузера ограничены Chromium и мобильной эмуляцией. Проверки настоящего устройства и реального ремонта не выполняются: каталог намеренно вымышленный.

Локальный прогон 29.10.2026: 62 модульных и компонентных теста всего репозитория (21 для RePair Atlas), 46 E2E-сценариев (14 для RePair Atlas). Production-сборка успешна. npm audit: 0 известных уязвимостей на момент проверки.

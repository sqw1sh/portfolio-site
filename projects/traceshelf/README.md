# TraceShelf — карта доказательств решений

Рабочий локальный MVP на React + TypeScript + Vite. Стартовый набор явно помечен как вымышленные демоданные.

## Возможности

- Источники, утверждения и решения: создание, редактирование, удаление.
- Зависимости в направленном ациклическом графе; циклы, дубликаты и ссылки на отсутствующие записи отклоняются.
- Граф с масштабированием и доступная таблица. Поиск по тексту, фильтры по типу, статусу и владельцу.
- Даты проверки и срок актуальности источников. Панель причин показывает цепочку до проблемной записи.
- Версии содержимого и последовательный пересмотр: сначала доказательства, затем зависимые записи.
- Сохранение в localStorage, JSON-экспорт/импорт, пустое пространство и восстановление демо с подтверждением.

## Запуск из корня репозитория

```sh
npm ci
npm run dev:traceshelf
```

Vite откроет приложение на порту 4180. Полная статическая сборка: `npm run build`. Общий preview (`npm run preview`) обслуживает портфолио и `/traceshelf/`.

Публичный адрес после публикации: [TraceShelf](https://sqw1sh.github.io/portfolio-site/traceshelf/).

## Стек

React Router — адрес выбранной записи; React Query — снимок локального адаптера и мутации; Zustand — фильтры, режим и масштаб; React Hook Form + Zod — формы; Tailwind + CSS — оформление. Данные пространства не дублируются в Zustand.

## Структура

- `app/src/model.ts` — схема v1, инварианты DAG, пути доказательств, статусы и операции.
- `app/src/repository.ts` — проверка и запись локального снимка, импорт/экспорт.
- `app/src/TraceShelf.tsx` — workspace, React Query, фильтры и операции.
- `app/src/components.tsx` — формы, граф и панель записи.
- `app/src/model.test.ts` — модульные проверки модели и сохранности данных.
- `../../tests/e2e/traceshelf.spec.ts` — браузерные сценарии в desktop/mobile.

## Ограничения MVP

200 записей, 800 связей, импорт до 1 МБ. Нет аккаунтов, сервера, совместного редактирования и синхронизации между устройствами. Разные вкладки подхватывают storage-события; конфликты одновременного редактирования не разрешаются автоматически. Для резервной копии нужен экспорт JSON. Очистка данных сайта удаляет локальное пространство.

Актуальность означает соблюдение заданного срока и подтверждение версии, а не автоматическую проверку достоверности источника.

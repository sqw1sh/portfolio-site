# TraceShelf — карта доказательств решений

## Идея

Рабочее пространство, где каждое решение связано с утверждениями и первоисточниками. Изменение или устаревание источника подсвечивает решения, которые нужно пересмотреть.

## MVP

- Создание источника, утверждения и решения; связи между ними.
- Граф и доступный табличный режим с фильтрами по статусу и владельцу.
- Дата проверки источника и правило устаревания; без обещания автоматической проверки достоверности.
- Панель «почему решение требует пересмотра» с цепочкой зависимостей.
- JSON-импорт/экспорт и отдельный набор явно обозначенных демоданных.

## Архитектура

React + TS + Vite + React Router, React Query, Zustand для фильтров и выбора узла, Tailwind, React Hook Form + Zod. На первом этапе — детерминированный локальный адаптер данных; настоящий API и совместное редактирование — отдельное расширение.

## Критерии готовности

Циклическая связь отклоняется с объяснением. Изменение источника пересчитывает зависимые статусы. Некорректный импорт не повреждает текущие данные. Все операции графа доступны из таблицы с клавиатуры. Добавить тесты обхода графа и E2E «источник → решение → пересмотр».

## Кейс

Показать модель графа, стратегию инвалидирования кеша и компромиссы локального хранения. Измерить время пересчёта на фиксированном наборе данных; результаты публиковать только после замера.
